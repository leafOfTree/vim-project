# Colorscheme of the demos

`colors/onedark.vim` and `autoload/onedark.vim` are copied unchanged from
[joshdick/onedark.vim](https://github.com/joshdick/onedark.vim) (57b7774),
under the MIT license in `LICENSE-onedark`. `docs/demo/vimrc` adds this folder
to 'runtimepath' so the recordings look the same on any machine.
